# Le plateau's engine files

Copied unchanged from Ilyan Hamdane's `le-plateau` (repo `zziadissa117/le-plateau`, commit `f3c8678`), with his
permission: `remixer.py` (clips, trims, variation, captions, music, encode), `sons.py` (song library, chorus,
rotation), `captions.py` / `captions_pil.py` (on-screen text) and the TikTok Sans font (SIL OFL, `fonts/OFL.txt`).
Comments are in French and say why each choice was made.

`plateau.py` here is a stand-in: the engine has no Le plateau database. Paths are pointed at the engine's data
folder by `engine/engine/plateau_paths.py`. Change these files only to fix a bug, and say so in the CHANGELOG.
